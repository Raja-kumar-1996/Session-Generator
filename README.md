# 📋 How It Works

1. Enter your API ID.
2. Enter your API HASH.
3. Enter your Telegram phone number.
4. Verify the OTP sent by Telegram.
5. Enter your Two-Step Verification password (if enabled).
6. Copy your generated String Session.
7. Store it securely.
